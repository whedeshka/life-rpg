# LIFE RPG — Прокачай свою жизнь

Мобильное приложение в стиле RPG: превращай реальные дела в квесты, получай опыт и монеты, повышай уровень и развивай навыки.

## Запуск

Требуется Node.js 20.19.4+.

```bash
npm install
npx expo start
```

Открой Expo Go на телефоне и отсканируй QR-код. Для Android/iOS можно собрать production-билд через EAS Build.

## Возможности MVP

- Ежедневные квесты и награды XP/монетами
- Уровни персонажа и прогресс-бар
- Навыки: интеллект, сила, дисциплина, кулинария
- Серия привычек и достижения
- Локальное сохранение прогресса на устройстве

## Технологии

Expo · React Native · TypeScript · AsyncStorage
