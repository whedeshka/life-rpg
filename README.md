# LIFE RPG — Прокачай свою жизнь

Мобильная RPG для реальной жизни: превращай повседневные дела в квесты, получай опыт и монеты, повышай уровень и развивай навыки.

## Сборка APK через GitHub

Проект собирает Android APK через **React Native CLI (без Expo и EAS)**.

1. Открой вкладку **Actions** в репозитории.
2. Выбери workflow **Build Android APK**.
3. Нажми **Run workflow** (или дождись сборки после push в `main`).
4. Открой завершённый запуск workflow.
5. Внизу страницы скачай artifact **life-rpg-debug-apk** и распакуй ZIP — внутри будет `app-debug.apk`.

Это debug-сборка для установки и тестирования, не релиз для Google Play.

## Что есть в MVP

- Ежедневные квесты и награды XP/монетами
- Уровни персонажа и прогресс-бар
- Навыки и достижения
- Серия привычек
- Локальное сохранение прогресса на устройстве

## Технологии

- React Native CLI (Bare React Native)
- TypeScript
- AsyncStorage
- GitHub Actions + Gradle для сборки Android APK
- Supabase SDK добавляется в сборочную среду; подключение проекта и облачная синхронизация — следующий этап

## Важно

GitHub Actions создаёт нативный Android-проект React Native во время сборки и использует корневой `App.tsx` как экран приложения. Supabase не собирает APK: он будет отвечать за аккаунты и облачные данные.
